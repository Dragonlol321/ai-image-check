AI IMAGE CHECK — PYTHON 3.15

Запуск:
1. Убедись, что установлен Python 3.15 (64-bit).
2. Распакуй архив в отдельную папку.
3. Запусти start.bat.
4. Дождись установки библиотек.
5. Открой http://127.0.0.1:5000.

Что изменено для Python 3.15:
- Используется отдельное виртуальное окружение именно Python 3.15.
- Pillow обновлён до версии 13+, которая официально поддерживает Python 3.15.
- Для PyYAML отключается необязательное C-расширение LibYAML, чтобы избежать
  ошибки компиляции Microsoft Visual C++ Build Tools.
- Установка ML-библиотек выполняется в окружении Python 3.15.

Важно:
- На Windows x64 PyTorch публикует колёса для Python 3.15 начиная с версии 2.15.
- Совместимость всей цепочки ML-зависимостей зависит от доступных колёс на момент установки.
- Первая установка и загрузка модели могут занять много времени и места на диске.
- Для загрузки модели нужен интернет.
- Сайт доступен только на этом компьютере по адресу 127.0.0.1:5000.
- Файл изображения удаляется после анализа.
- Результат модели — оценка вероятности, а не доказательство.
